# loglint

Линтер для проверки лог-сообщений в Go-коде.

## Структура
- internal/loglint — основной анализатор
- testdata — тестовые файлы
- cmd — CLI/интеграция

## Установка зависимостей
```
go mod tidy
```

## Запуск
```
go run ./cmd/loglint
```

## Использование с golangci-lint

Инструкция будет добавлена после реализации плагина.

## Проверяемые правила
1. Сообщение начинается со строчной буквы
2. Сообщение только на английском языке
3. Нет спецсимволов и эмодзи
4. Нет чувствительных данных

## Примеры
- log.Info("starting server")
- slog.Error("failed to connect to database")

## Тесты
```
go test ./internal/loglint
```
